# YouTube Playlist to Spotify/Apple Music Prototype

## Features
- Paste a YouTube playlist link
- Choose Spotify or Apple Music
- See which songs can be transferred (mocked for now)

## Stack
- Frontend: React
- Backend: Node.js/Express

## How to run
1. Install dependencies: `npm install` in both `frontend` and `backend` folders
2. Start backend: `npm start` in `backend`
3. Start frontend: `npm start` in `frontend`
